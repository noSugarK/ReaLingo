安装与使用Install and use

  1. 下载 .exe（推荐）或 .msi，双击安装。Download the .exe (recommended) or .msi and run it.
  2. 安装包没有代码签名，SmartScreen 可能提示「Windows 已保护你的电脑」：点 更多信息 → 仍要运行。The installer is not code-signed, so SmartScreen may say "Windows protected your PC": click More info → Run anyway.
  3. 从开始菜单打开 ReaLingo。Windows 11 会把托盘图标折叠进 ^，想常驻就拖到任务栏上。Open ReaLingo from the Start menu. Windows 11 folds new tray icons under ^; drag it onto the taskbar to keep it visible.
  1. 下载 .dmg，打开后把 ReaLingo 拖进「应用程序」。Download the .dmg, open it and drag ReaLingo into Applications.
  2. 应用没有经过 Apple 公证，首次打开会被拦下（提示「已损坏」或「无法验证开发者」）。在终端执行一次：The app is not notarised, so the first launch is blocked ("damaged" or "unidentified developer"). Run once in Terminal: 
    xattr -dr com.apple.quarantine /Applications/ReaLingo.app
    或者先打开一次，再到 系统设置 → 隐私与安全性，在页面下方点 仍要打开。Or open it once, then click Open Anyway at the bottom of System Settings → Privacy & Security.
  3. 首次用麦克风 / 系统声音时会弹权限申请，点允许。系统声音需要 macOS 14.4+。Allow the microphone / system audio permission when asked. System audio needs macOS 14.4+.
  1. Ubuntu / Debian 下载 .deb 用 apt 安装，Fedora 下载 .rpm 用 dnf 安装，自动安装依赖：Use apt with the .deb on Ubuntu / Debian, or dnf with the .rpm on Fedora, to install dependencies automatically: 
    sudo apt install ./ReaLingo_*.deb
# Fedora (RPM)
sudo dnf install ./ReaLingo_*_linux_x86_64.rpm

  3. 系统声音需要 PulseAudio 或 PipeWire（Ubuntu 桌面默认就有）。托盘图标不响应左键，用右键菜单里的「显示主窗口」。System audio needs PulseAudio or PipeWire (standard on the Ubuntu desktop). The tray icon ignores left clicks; use "Show main window" in its right-click menu.

1. 挑一家服务，拿到 API Key

只需要一家。不知道选哪家，先看模型与价格；ReaLingo 的设置页里也有各家控制台的直达链接。

  • 阿里云百炼（Qwen）：打开百炼控制台的 API Key 页（国际站账号用新加坡地域），创建一个 API Key 并复制。Key 跟地域对应：国内站选北京，国际站选新加坡，后面在设置里选同一个地域。Qwen3.8 和 Qwen3.5 共用这一个 Key。北京地域的免费额度要先到免费额度页手动开通；新加坡地域开通百炼后自动发放，但 Qwen3.5 已停发新用户额度。额度以控制台实际为准。 阿里云高校学生优惠 ↗
  • OpenAI：在 OpenAI 平台的 API keys 页新建一个 secret key，完整的 Key 只显示这一次，马上复制。账号里需要有可用余额。
  • Google Gemini：在 Google AI Studio 的 API Key 页创建 Key 并复制。有免费层，限额在用量限制页查看，以实际为准。
  • 火山引擎豆包：先到开通管理里手动开通「同声传译」（开通后发放 100 万 token 免费额度，以控制台实际为准），再到豆包语音控制台的 API Key 页创建 Key。没开通的话，Key 填进去也连不上。

2. 把 Key 填进 ReaLingo

桌面端点右上角齿轮（或标题栏下的模型名），在「连接」里选接口并粘贴 Key；Android 点模型卡片选接口，在设置中填写 Key。用百炼时再确认地域。桌面端使用可用的系统凭据库；Android 当前将 Key 明文保存在应用私有配置中，Linux 无凭据库时也使用此回退。不要共享包含 Key 的配置文件。

3. 开始翻译

  1. 选音频来源：麦克风、系统声音或音频文件。
  2. 选目标语言。豆包还要指定源语言，其余接口能自动识别。
  3. 想听译文就打开朗读，想在别的窗口上看字幕就打开字幕窗。
  4. 点「开始翻译」。

连不上时，先到设置页「高级」里看最终连接的地址，确认接口、地域和 Key 是同一家、同一个地域的。

1. Pick a service and get an API key

You only need one. Not sure which? See Models & pricing. ReaLingo's settings page also links straight to each console.

  • Alibaba Cloud Model Studio (Qwen): open the API key page in the Model Studio console (China-site accounts use the Beijing region), create a key and copy it. Keys follow the region: international accounts use Singapore, China-site accounts Beijing; pick the same region in Settings later. Qwen3.8 and Qwen3.5 share this key. In Beijing the free quota must be switched on first on the free quota page; in Singapore it is granted automatically once Model Studio is activated, though Qwen3.5 no longer gives new users any. The console has the final word. Alibaba Cloud university student offer ↗
  • OpenAI: create a new secret key on the API keys page of the OpenAI platform. The full key is shown only once, so copy it right away. The account needs available credit.
  • Google Gemini: create a key on the API key page in Google AI Studio and copy it. There is a free tier; check its limits on the rate limit page, which has the final word.
  • Volcengine Doubao: first switch on simultaneous interpretation by hand under Activation (that grants 1M free tokens; the console has the final word), then create a key on the API key page of the Doubao Speech console. Without activation the key will not connect.

2. Put the key into ReaLingo

On desktop, open the gear (or model name below the title-bar logo) and select the provider under Connection. On Android, select the provider in the model card and enter the key in Settings. For Model Studio, confirm the region too. Desktop uses the OS credential store when available. Android currently keeps keys as plaintext in its app-private configuration; Linux without a credential store uses the same fallback. Do not share configuration files containing keys.

3. Start translating

  1. Pick the audio source: microphone, system audio or an audio file.
  2. Pick the target language. Doubao also needs the source language; the others detect it.
  3. Turn on read-aloud to hear the translation, and open the overlay to read subtitles over other windows.
  4. Press Start.

Can't connect? Settings → Advanced shows the final endpoint: check that the API, region and key all come from the same vendor and region.
